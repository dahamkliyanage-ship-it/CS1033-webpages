Python Lists

A Python list is a dynamically sized array. It can grow or shrink at runtime, making it useful for storing and organizing sequential data.

HETEROGENEOUS

Unlike standard arrays, Python lists can store different types of data in the same list, such as integers, strings, and other objects.

ITERABLE & ORDERED

The values in a list are an ordered collection where each value has a specific position. Because you can access locations via index values, a list is an iterable collection.

MUTABLE

Lists are strictly mutable. This means the exact values contained in a list can be altered, swapped, or deleted after the initial creation of the list without changing the memory location.

02. Indexing & Slicing

Python allows us to denote a specific range of elements using the colon symbol.

  • List[:Index] slices from the beginning to the denoted index.
  • List[Index:] slices from the specified index all the way to the end.
  • List[::-1] reverses the whole list instantly using the slicing operation.

03. Mutability in Memory

Because lists are mutable, their contents can be completely changed while their storage in memory remains untouched. We can prove this using the id() function, which returns the unique identity/memory address of an object.

mutability_check.py
# The memory address stays exactly the same!
L = [0, 1, 2, 3]
print(L, id(L)) # Output: [0, 1, 2, 3] 140308181206528

L[1] = 'B'
print(L, id(L)) # Output: [0, 'B', 2, 3] 140308181206528

04. Core List Methods

A list as an ADT provides a user with a set of typical functionalities to manipulate the data. Here are the heavy lifters you will use constantly:

append(value)

Appends a single value to the tail (end) of the list.

insert(position, value)

Allows the insertion of a value to a specific indexed location in the list.

extend(iterable)

Extends the list we are handling with the elements present in another list (or iterable) given as the argument.

remove(value)

Removes only the first matching element it encounters. Generates an error if the value is missing.

pop(position)

Removes an element at a specified position. If blank, it defaults to removing the last element.

sort() & reverse()

Rearranges the contents into increasing order, or reorders the contents so they are in reverse based on position.

05. Nested Lists as Matrices

Because lists can contain other lists, they are perfectly suited to represent multi-dimensional matrices. Using nested loops, complex matrix operations (like addition) can be done easily.

matrix_addition.py
M1 = [[1, 2], [3, 4]]
M2 = [[5, 6], [7, 8]]
M3 = [[0, 0], [0, 0]]

for idx in range(2):
    for idy in range(2):
        M3[idx][idy] = M1[idx][idy] + M2[idx][idy]

print(M3) # Output: [[6, 8], [10, 12]]
