TOPIC 10.3: THE FAST LOOKUP

Python Dictionaries

Both the primary data types and structured types like lists, tuples, and sets store each data element as a single value[cite: 9]. In contrast, the dictionary data type stores each data element as a pair of values called a key and a value[cite: 9].

THE KEY

The key is used to handle the storing of data elements in an optimized manner[cite: 9]. Crucially, the key in a dictionary must be entirely unique and it must be of an immutable data type[cite: 9].

THE VALUE

Unlike keys, the values in a dictionary can be of absolutely any data type and can be freely duplicated throughout the structure[cite: 9].

THE LOOKUP

This structure maps the key-part directly to the value-part, allowing you to access the values in a dictionary incredibly efficiently, just like searching for a word in a real-world dictionary[cite: 9].

02. Creation & Structure

There are two main ways to forge a dictionary in Python: grouping a collection of comma-separated data elements inside curly brackets {}, or using the built-in dict() function[cite: 9]. Each element inside is separated by a colon key: value[cite: 9].

03. Adding & Updating Elements

You can push new data into your dictionary or update existing data using two distinct methods: direct key access or the built-in update() function[cite: 9].

direct_access.py
# Directly assigning via keys
TT = {} # Empty Dictionary
TT[1] = 'Programming'
TT[2] = 'Mathematics'

# Updating an existing key
TT[1] = 'CS Programming'
update_method.py
# Passing an iterable list of pairs
TT.update([(1, 'CS Programming')])

# Passing another dictionary
TT.update({5: 'Mechanics'})

# If the key isn't present, it adds it as a new element.

04. Removing Elements

In Python, there are exactly 4 methods to completely obliterate data from a dictionary[cite: 9]. Use them wisely.

del Dict[key]

Deletes a specific entry using its key[cite: 9]. You can also use del Dict to wipe the entire dictionary out of existence, causing an error if you try to access it later[cite: 9].

pop(key)

Removes a specific entry using the key, but crucially, it returns the data value before deleting the full entry[cite: 9].

popitem()

Removes and returns an arbitrary element as a tuple pair[cite: 9]. In practice, it usually removes the very last item added to the dictionary[cite: 9].

clear()

Unlike del, the clear() method deletes all items at once, leaving behind a perfectly empty but still accessible dictionary in your program[cite: 9].

05. Accessing Data & Functions

When pulling data out of a dictionary, using the index operator Dict[key] works perfectly, but it will trigger a fatal run-time error if the key doesn't exist[cite: 9]. The safer route is the get() function.

>> THE SAFE LOOKUP: get()

The built-in get() function attempts to find the key. If a matching key is not found, it simply returns None instead of generating a program-crashing error[cite: 9].

Essential Dictionary Methods

  • len(dict): Returns the total number of items in the dictionary[cite: 9].
  • dict.keys(): Returns a new object containing the complete set of keys[cite: 9].
  • dict.values(): Returns a new object containing the complete set of values[cite: 9].
  • dict.items(): Returns a new object containing the set of items, packaged as tuples[cite: 9].
  • dict.setdefault(key, value): Returns the value if the key exists. If it doesn't, it creates the key and sets it to the provided value[cite: 9].
