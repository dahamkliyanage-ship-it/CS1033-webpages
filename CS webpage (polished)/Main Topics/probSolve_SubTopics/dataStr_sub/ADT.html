TOPIC 11: ADVANCED ORGANIZERS

Abstract Data Structures

Lists, Tuples, and Dictionaries are built directly into Python. But what happens when you need to engineer a custom data engine? You build an Abstract Data Type (ADT)—a mathematical model of data defined entirely by its behavior as seen by the user[cite: 9].

Linear vs. Hierarchical

Stacks and Queues are linear data structures (elements are explicitly behind or in front of each other)[cite: 9]. Trees are hierarchical[cite: 9].

The Interface

An ADT hides the internal mechanics. The user only sees the operations they are allowed to perform, like push() or pop()[cite: 9].

02. The Stack (LIFO)

A stack is a Last-In/First-Out (LIFO) storage structure[cite: 9]. Insertion or removal occurs only at one specific position: the top of the stack[cite: 9]. Think of it like a stack of plates—you can only take the top one off.

  • top() / peek(): Returns the top element without removing it, because in a stack, only the top item is visible to an outsider[cite: 9].

03. The Queue (FIFO)

A queue represents a familiar real-world line of people[cite: 9]. It is a First-In/First-Out (FIFO) storage structure where insertion happens at the tail, and removal happens at the head[cite: 9].

>> CORE QUEUE OPERATIONS
  • insert(item) / enqueue: Inserts an item at the tail[cite: 9].
  • remove() / dequeue: Removes the item at the front (head)[cite: 9].
  • front() & rear(): Returns references to the elements at the head and tail, as those are the only items visible to an outsider[cite: 9].

04. Hierarchical Trees

Most of the data we use in the real world has a hierarchical structure (like a file system or an academic record)[cite: 9]. A Tree ADT is visualized as an upside-down tree[cite: 9].

The Root

The topmost node of the data structure. It is the single entry point for the entire tree[cite: 9].

Children & Parents

Elements directly under a given element are its children, and the element directly above it is its parent[cite: 9].

Leaves

The terminal nodes at the very bottom of the structure that possess absolutely no children[cite: 9].

Binary Trees

A specific type of tree where every single element has a maximum of exactly 2 children (Left and Right)[cite: 9].

05. Tree Traversal

Because trees are not linear, you cannot just iterate from index 0 to 10. You must use recursion to traverse them[cite: 9]. The two main strategies are Breadth-First (level by level) and Depth-First (diving to the deepest leaf first)[cite: 9].

>> DEPTH-FIRST TRAVERSALS
  • Preorder: Visit Root → Traverse Left → Traverse Right. (Great for creating a direct copy of a tree)[cite: 9].
  • Inorder: Traverse Left → Visit Root → Traverse Right.
  • Postorder: Traverse Left → Traverse Right → Visit Root. (Perfect for safely deleting a tree from the bottom up)[cite: 9].
