TOPIC 10.2: THE LOCK & KEY

Tuples & Sets

While lists are completely dynamic, sometimes you need data to be permanently locked in place. A tuple is defined as a finite, ordered list of elements that is strictly immutable. Once you create it, you cannot alter it.

N-TUPLE

Tuples are denoted mathematically by their size: a 1-tuple is a singleton, a 2-tuple is an ordered-pair, and a 3-tuple is a triplet. You can even have an empty 0-tuple.

THE COMMA QUIRK

Tuples are created with comma-separated values, typically grouped by parentheses (). However, to create a single-element tuple, parentheses aren't enough—you must include a trailing comma (e.g., ('test',)).

MIXED TYPES

Just like lists, tuples are completely heterogeneous. You can pack integers, strings, and even other tuples into a single variable.

02. Unpacking & Swapping

Because tuples are strictly ordered, Python allows you to easily "unpack" their contents into separate variables or use them to cleanly swap data without needing a temporary placeholder.

unpacking.py
# Unpacking elements into variables
T = ('Dept', 'of', 'CSE')
a, b, c = T

print(a, b, c) # Output: Dept of CSE
swapping.py
# Flawless variable swapping
a = 'Alpha'
b = 'Bravo'

(a, b) = (b, a) # The Swap
print(a, b) # Output: Bravo Alpha

03. Sets: The Unique Collection

In mathematics, a set is defined as a collection of distinct objects. Python takes this mathematical concept and turns it into a powerful Abstract Data Type (ADT).

>> THE 4 RULES OF SETS
  • Unordered: Elements have no specific order or index positions.
  • Iterable: You can loop through the collection.
  • Mutable: You can add or remove items from the set itself.
  • No Duplicates: The set will automatically destroy any duplicate values you try to insert.
>> THE IMMUTABILITY CATCH

While the set itself is mutable, the individual elements inside the set cannot be of a mutable data type. You can put a tuple inside a set, but you cannot put a list or a dictionary inside a set.

04. Core Set Mechanics

Because sets do not have indexes, you manipulate them differently than lists. You create them using curly brackets {} or the built-in set() function.

add() vs update()

Use .add() to insert a single element. Use .update() to pass an iterable (like a list) and add multiple elements at once.

remove() vs discard()

Both delete an element. However, .remove() will crash your program with an error if the element is missing, while .discard() fails silently without crashing.

05. Set Mathematics

Sets are built for high-speed mathematical operations. Instead of writing massive loops to compare two databases, you can use these core geometric commands.

Union ( A | B )

Returns a new set containing all elements present in both A and B, combined.

Intersection ( A & B )

Returns the largest set of elements that are strictly common to both A and B.

Difference ( A - B )

Returns all elements present in A that are not present in B[: 10].

Symmetric Diff ( A ^ B )

Returns elements present in either A or B, but strictly excluding the elements common to both.

>> BOOLEAN TESTS

You can also ask Python true/false questions about sets: A.isdisjoint(B) checks if they share absolutely no elements. A.issubset(B) checks if all of A is inside B.
